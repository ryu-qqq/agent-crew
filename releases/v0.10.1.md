# v0.10.1 — journal-recorder git 미관여 명문화

- **날짜**: 2026-06-02
- **유형**: PATCH
- **이전**: v0.10.0
- **검증 상태**: 미검증

> 이 파일은 `releases/TEMPLATE.md`를 복사해 채운다. 작성·태그 절차는 VERSIONING.md "릴리스 기록" 참조.

## 이 릴리스는

journal-recorder가 스펙에 없는 git 커밋을 즉흥적으로 수행해, 멀티프로젝트가 공유하는
단일 vault 레포의 *현재 체크아웃된 브랜치*(다른 프로젝트의 작업 브랜치)에 시드를 얹어
남의 PR을 오염시키는 문제를 막기 위한 PATCH. 핵심 원칙에 "git 미관여"를 명문화합니다.

## 자산별 변경

### `agents/journal-recorder.md` — 수정

- **변경**: 핵심 원칙 #7 "git에 손대지 않는다" 추가 — `git add`·`commit`·`checkout`·`push`
  미수행. `knowledge.vault.git: true` 여도 커밋하지 않으며, 커밋이 필요하면 호출자(journal
  스킬)·사람이 브랜치를 인지해 별도 수행한다. push는 어떤 경우에도 하지 않는다.
- **개선**: 기존 스펙은 git을 일절 언급하지 않아(allowed-tools에 Bash도 없음) 에이전트가
  커밋 여부·대상 브랜치를 즉흥 판단했습니다. 그 결과 공유 vault의 타 프로젝트 브랜치에 시드가
  얹히는 사고가 실제로 발생. 동작을 명시적으로 금지해 "시드만 쌓는다(순수 관찰자)"는
  본래 정체성과 일치시키고 책임을 분리했습니다.
- **동기**: parallel 프로젝트의 ADR 결정 시드 기록 중, vault가 fileflow 작업 브랜치에
  체크아웃된 상태에서 journal-recorder가 그 브랜치에 커밋한 사고(2026-06-02)에서 출발.
