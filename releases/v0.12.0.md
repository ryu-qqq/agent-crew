- **이전**: v0.11.0
- **검증 상태**: 해당 없음 — 자산 *동작*은 바뀌지 않았다. frontmatter 키·YAML 파싱 정합뿐. (이 문서는 태그만 있고 누락돼 있던 릴리스 기록을 사후 보충한 것 — v0.13.0 작업 중 발견.)

## 이 릴리스는

자산 frontmatter를 Claude Code 정식 스키마에 맞추고, YAML 파싱이 깨지던 버그를
잡는 **정합 릴리스**다. 새 자산·동작 변경은 없다. 잘못된 frontmatter 키 때문에
서브에이전트 tools 선언이 무시되거나 skill description이 안 읽히던 것을 바로잡는다.

## 자산별 변경

### `agents/*.md` (16개) — 수정 (frontmatter 키 정정)

- **변경**: 서브에이전트 frontmatter의 `allowed-tools` → **`tools`** 로 정정. `tools`가 Claude Code 서브에이전트의 정식 키다(`allowed-tools`는 skill 쪽 키라 agent에선 무시됐다).
- **개선**: tools 선언이 실제로 적용된다 — 키가 틀려 도구 제한이 먹지 않던 잠재 버그 해소.
- **동기**: agent와 skill의 frontmatter 키가 다른데(agent=`tools`, skill=`allowed-tools`) agent에 skill 키가 붙어 있었다.
- **대상**: adr-author · agent-evaluator · decision-researcher · harness-author · harness-trigger-designer · jira-manager · journal-recorder · notion-doc-writer · notion-manager · proposal-applier · proposal-reviewer · scenario-designer · test-strategist · wiki-curator · wiki-lookup · work-evaluator.

### `skills/journal/SKILL.md` — 수정 (YAML 파싱 버그)

- **변경**: frontmatter `description`을 작은따옴표로 감쌌다. 값 안의 `모드: `(콜론+공백)이 YAML 매핑으로 오해돼 frontmatter 전체가 안 읽히던 버그를 해소.
- **개선**: journal 스킬 메타데이터가 정상 로드된다.
- **동기**: plain scalar에 콜론+공백이 들어가면 YAML이 매핑 키로 파싱한다(skill description 작성 시 흔한 함정 — 이후 자산은 콜론을 피하거나 인용한다).

### `CHANGELOG.md` — 인덱스 갱신 (사후 보충)
