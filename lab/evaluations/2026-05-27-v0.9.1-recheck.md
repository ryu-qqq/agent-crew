## agent-evaluator 재채점 — 차원 1 변화

| 항목 | v0.9.0 | v0.9.1 |
|---|---|---|
| (a) LLM 기본지식 중복 X | ✓ | ✓ |
| (b) 중요 정보 시작·끝 위치 | ✓ | ✓ |
| (c) 1024+ 토큰 안정 prefix | ✓ | ✓ |
| (d) sub-agent 위임 권장 명시 | ✓ (일반론) | ✓ (**context-preprocessor 구체 명시**) |
| **차원 1 점수** | **5** | **5** (변화 없음) |
| **종합** | **32** | **32** |

### 발견 — 점수 변화 0, 질적 향상 있음

이미 차원 1 만점(5)이라 한 줄 추가로 점수 *수치*는 안 올라감. 단:
- v0.9.0: "sub-agent 위임 권장"이 *일반 원칙*으로 명시 (Step 3 한 줄)
- v0.9.1: 호출할 *구체적 자산*(context-preprocessor) 명시 — **근거 구체화**

→ **rubric의 한계 노출**: 차원 1 (d) 측정 항목이 *"위임 권장 명시 여부"* 만 본다. *"얼마나 구체적으로 명시했나"* (일반론 vs 구체 자산)는 채점 못 함. 같은 5점 안에 *질적 격차* 있음.

### 후속 (rubric v1.2 후보)

차원 1 (d)를 1단계 → 2단계로:
- (d-i) sub-agent 위임 가능성 인지 명시
- (d-ii) 호출할 구체 자산·skill 명시

agent-evaluator는 (d-ii)까지 충족 → 5점, work-evaluator·proposal-reviewer는 (d-i)만 → 4점으로 더 정밀 채점 가능.

→ 이건 차원 1 측정 *세분화* 검토. 현재는 점수에 반영 X (channel ≠ 척도).
